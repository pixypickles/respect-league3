# Futsal Trap Game

スマホ横持ち用のHTML5フットサルゲーム・プロトタイプです。  
GitHub Pagesへそのまま配置して遊べます。

## 操作

### スマホ
- 左スティック: 移動
- PASS:
  - ボール所持中: パス
  - パスが味方へ届く前: リターンパス要求
  - CPU味方が所持: 自分へパス要求
  - 守備中: ボールをつつく
- TRAP:
  - パス・シュートを受ける瞬間に押すとトラップ
  - 押し続けるとボール保持・ドリブル
  - 離すとボールが足元から離れる
  - GKがボールへ触れる瞬間に押すとスーパーキャッチ
- SHOT:
  - 超短押し: ループシュート
  - 普通押し: 通常シュート
  - 長押し: 強シュート
  - 守備時: スライディング
- DASH: ダッシュ

### PCテスト
- 矢印キー: 移動
- Z: TRAP
- X: DASH
- A: PASS
- S: SHOT

## CPU方針
- パスを優先
- 敵が遠い場合だけ前進ドリブル
- 味方はパスコース・空いたスペースへ動く
- CPU同士でもパスを行う
- 守備側CPUは近距離でボールをつつく/スライディング

## GitHub Pages
1. このフォルダ内のファイルをGitHubリポジトリへアップロード
2. GitHubの `Settings` → `Pages`
3. `Deploy from a branch`
4. `main` / `/ (root)` を選択
5. 公開URLをスマホで開く

## 主な調整ポイント
`game.js` 冒頭付近の以下を変更するとゲーム感を調整できます。

- `PLAYER_R`
- `MATCH_SECONDS`
- `p.speed`
- パス速度 `420`
- 通常シュート速度 `505`
- 強シュート速度 `610+`
- トラップ判定距離
- GKの `saveChance`
