# Futsal Trap Game

スマホ横持ち用のHTML5フットサルゲーム・プロトタイプです。  
GitHub Pagesへそのまま配置して遊べます。

## 操作

### スマホ
- 左スティック: 移動
- PASS:
  - ボール所持中: パス
  - パスが味方へ届く前: リターンパス要求
  - CPU味方が所持: 自分へパス要求
  - 守備中: ボールをつつく
- TRAP:
  - パス・シュートを受ける瞬間に押すとトラップ
  - 押し続けるとボール保持・ドリブル
  - 離すとボールが足元から離れる
  - GKがボールへ触れる瞬間に押すとスーパーキャッチ
- SHOT:
  - 超短押し: ループシュート
  - 普通押し: 通常シュート
  - 長押し: 強シュート
  - 守備時: スライディング
- DASH: ダッシュ

### PCテスト
- 矢印キー: 移動
- Z: TRAP
- X: DASH
- A: PASS
- S: SHOT

## CPU方針
- パスを優先
- 敵が遠い場合だけ前進ドリブル
- 味方はパスコース・空いたスペースへ動く
- CPU同士でもパスを行う
- 守備側CPUは近距離でボールをつつく/スライディング

## v6 CPUパス処理の作り直し
- CPUは135px未満の近距離パスを原則選ばない
- パスコース上に相手がいる味方を候補から除外
- 受け手の周囲に敵が近すぎる場合も候補から除外
- CPUパス直後に約0.24秒のクリーンな飛行時間を追加

- CPUは受けた直後に約0.22秒ボールを落ち着かせてから次の判断
- プレッシャー時も安全なパスコースが無ければ連打せず、横へ逃げてコースを作る
- CPU同士の超短距離ワンタッチ連鎖を抑制


## v7 操作・攻撃AI調整
- TRAPを押していなくても、近くのルーズボールへPASS可能
- TRAPを押していなくても、近くのルーズボールへSHOT可能
- TRAPは「止める・保持する」ための操作として分離
- 味方AIはボール保持者より前へ2〜3人が出る攻撃配置へ変更
- 前に出る選手は縦レーンを分け、全員が同じ場所へ集まらない
- ボール周囲のCPU除外距離を縮め、味方がプレーから離れすぎないよう調整
- CPUもルーズボールへ近ければダイレクトパス可能


## v8 難易度・ルーズボール調整

- ルーズボールへのPASS/SHOT反応距離を拡大

- 受け手が極端に遠い/厳しくマークされている場合はNO PASSになる


## v9 テンポ・トラップ・攻撃AI調整
- 通常パス速度を少し低下
- CPUパス速度も全体的に低下
- リターンパス速度も少し低下
- 低速のボール／こぼれ球は操作選手が自動トラップ
- 自動トラップ後は約0.34秒だけ自然に足元へ収める
- 高速パスやシュートは従来通りTRAPタイミングが重要
- CPUはパス後、約1秒前方スペースへ抜ける
- 敵CPUは受けてすぐ離さず、0.7秒以上キープして判断する場面を増加
- 敵CPUはフリーなら前へドリブル、軽いプレッシャーならキープして様子を見る
- 敵CPUのパス頻度をさらに下げ、ワンタッチ連続パスを抑制


## v10 自動トラップとPASS/SHOT競合修正
- 自動トラップ対象を本当に遅いボール（速度115未満）へ限定
- パス対象が設定されたボールは自動トラップしない
- PASS/SHOT入力を自動トラップより優先
- 自動トラップ保持時間を0.34秒から0.18秒へ短縮

- 近距離ボールへの直接操作範囲を少し拡大


## v11 シュート操作・守備アクション調整
- 守備時のSHOTボタンはスライディングではなくショルダーチャージ
- 近距離の相手へ体を当て、成功すると相手が約0.48秒よろける

- よろけ中は移動・AI判断が一時的に止まる
- SHOT長押し中に近くへ来たボールもシュート対象として拾う
- シュート対象の反応距離を拡大
- 低〜中速のルーズボールならチャージ中に足元へ収めてそのままシュート可能
- リリース時のボール判定も広げ、シュートが空振りしにくいよう調整


## v12 シュートとオートトラップの分離
- SHOT長押し中、近くのルーズボールを所有状態へ変換しない
- シュートはボールを止めず、そのまま現在位置から直接蹴る

- 自分が撃ったボールを直後に自動で拾い直す挙動を防止

- SHOT入力がTRAP処理より常に優先


## v13 ダイレクトプレー・守備操作・首振り調整
